# 경제전망 보고서 출력 계약

상태: **1차 HTML 편집·PDF 저장 작업공간 구현 · 구조화 패키지·Word 출력 대기**
기준일: 2026-08-24

## 1. 판정

`/outlook`의 섹터 카드와 차트는 보고서 입력 원장이다. `/outlook/report`에서 브라우저 자동저장,
본문 직접 편집, 단일 HTML 다운로드, A4 인쇄·PDF 저장을 제공한다. `report.json`·Word 출력,
모듈 이동·삭제·되돌리기, 최종 PDF 전 페이지 렌더 QA는 후속 구현 대기이므로 전체 완료로 판정하지 않는다.

## 3. 보고서 패키지

```text
outputs/YYYY-MM-DD-economic-outlook/
├── index.html       # 편집 가능한 정본
├── report.json      # 구조화 상태
├── report.pdf       # A4 출력본
├── report.docx      # 요청 시 Word 출력본
├── data/            # 차트에 사용한 정규화 표
└── sources/         # 출처·기준일·수집 상태 원장
```

PDF와 Word는 `index.html`에서 파생한다. 화면과 출력본에 서로 다른 내용을 따로 저장하지 않는다.

## 4. 보고서 순서

1. 표지와 기준일
2. 헤드라인 기계 판정
3. 신호 보드
4. 핵심 주장
5. 섹터별 근거 차트
6. 잠재성장률 시나리오
7. 리스크·확인 조건·전망 수정 조건
8. 교차검증
9. 데이터 주의
10. 출처·수집

헤드라인과 핵심 주장은 원자료에서 기계적으로 확인 가능한 변화만 초안으로 제시한다. 최종 경제전망과
시장 판단은 사용자가 승인하기 전까지 `검토대기 · AI 초안` 상태를 유지한다.

## 5. 섹터 모듈

보고서 모듈은 Cockpit의 섹터 ID를 그대로 사용한다.

| 순서 | 섹터 | 보고서 상태 |
|---:|---|---|
| 1 | 성장 | 연결된 공식 계열 사용 |
| 2 | 수출입 | 연결 계열 사용, 일평균 수출은 관세청 공식 게시판에서 검증된 월만 표시 |
| 3 | 재정 | 연결 계열과 문서 빈티지 구분, 월간 총수입·총지출·국고채 진도율의 서로 다른 기준월 보존 |
| 4 | 노동시장 | 연결 계열 사용, 서비스업 합계 산식 확정 전 결측 표시 |
| 5 | 자본계정 | 내용 확정 전 빈 모듈을 출력하지 않음 |
| 6 | 물가 | 연결 계열 사용, 원유도입단가는 산업통상부 공식 문서에서 검증된 시점만 표시 |
| 7 | 설비투자 | ECOS·KOSIS·K-stat 공식 계열 사용 |
| 8 | 건설투자 | 연결된 공식 계열 사용 |
| 9 | 국가재정운용계획 | 내용 확정 전 빈 모듈을 출력하지 않음 |
| 10 | 국내 유동성 | 연결 계열 사용, 금투협 키 필요 계열은 미연결 표시 |

모듈마다 다음 순서를 지킨다.

- 섹터 신호 또는 확인된 변화
- 근거 차트
- 주장
- 주의사항
- 기준일
- 출처

## 6. 잠재성장률 시나리오

기본 입력값은 `1.5%`, `1.7%`, `2.0%` 세 가지이며 사용자 입력으로 수정 가능해야 한다.
수정 시 모든 관련 표·차트·문안이 같은 입력 원장을 참조한다.

| 시나리오 | 잠재성장률 | 전제 | 성장·물가 경로 | 확인 조건 |
|---|---:|---|---|---|
| 하방 | 1.5% | 사용자 입력 | 사용자 승인 전 `—` | 사용자 입력 |
| 기준 | 1.7% | 사용자 입력 | 사용자 승인 전 `—` | 사용자 입력 |
| 상방 | 2.0% | 사용자 입력 | 사용자 승인 전 `—` | 사용자 입력 |

잠재성장률 변경만으로 실제 GDP·물가 경로를 자동 창작하지 않는다. 별도 모델 결과가 없으면 빈 값으로 둔다.

## 7. 차트 캡션

모든 차트는 다음 메타데이터를 가진다.

```text
주장: [사용자 승인 또는 기계적으로 확인된 변화]
주의사항: [빈도·계절조정·변환·결측·정의 차이]
단위: [% / 조원 / 지수 / 달러 등]
기준일: YYYY-MM 또는 YYYY-Qn
출처: [원천기관과 통계표]
```

차트는 API 원자료로 다시 그린 SVG/HTML을 사용한다. 보고서·스크린샷 차트를 최종 그림으로 붙이지 않는다.

## 8. 문체·시각

- 흰색 A4 캔버스, 검정·회색 본문, 코발트 블루 한 색의 핵심 강조
- 위험·음수만 제한적으로 빨간색 사용
- 숫자는 모노스페이스, 얇은 구분선, 평면 구성
- 큰 민트 대시보드 헤더·그라데이션·무거운 그림자·장식용 카드 금지
- 본문은 `~다`, `~니다`, `~습니다` 종결 금지
- `전망`, `판단`, `필요`, `가능성`, `확대`, `축소`, `제한적`, `점검` 등 연구노트형 명사 종결 사용
- 같은 주장을 지지하는 작은 차트 두 개는 A4 한 행 2열 배치, 글자 크기가 무너지면 1열 전환

Cockpit 화면은 기존 민트 UI를 유지할 수 있으나, 보고서 아티팩트와 출력본은 위 인쇄 스타일을 적용한다.

## 10. 완료 게이트

다음 항목이 모두 통과해야 보고서 기능을 완료로 판정한다.

- 사용자 문안 무단 변경 없음
- 차트의 계열·축·기준선·최신값이 Cockpit 원장과 일치
- 원자료 결측 보간·추정 없음
- 관련 차트의 캔버스·제목·메타데이터 위치 통일
- 텍스트 편집·모듈 이동·삭제·되돌리기 동작
- 하나의 권위 있는 A4 인쇄 CSS만 존재
- PDF 전 페이지 PNG 렌더링 검수
- 잘린 한글·가로 오버플로·빈 마지막 페이지 없음
- 출처·단위·기준일 누락 없음
- DAAI 호출·노출 없음
