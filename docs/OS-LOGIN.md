# OS 계정 연동

운영 스튜디오는 `https://daishin-ai-research.vercel.app/api/report-studio-auth`에서
로그인 명단과 인증 결과를 받는다. OS의 활성 직원 등록·전화번호·ADMIN/STAFF 역할이 정본이다.
직원을 등록한 뒤 로그인 화면을 새로고침하면 나타나며 별도 환경변수 변경이나 재배포가 필요 없다.

- 전화번호 원문은 OS에만 보관한다. 입력한 뒤 4자리는 서버 간 HTTPS 검증 요청에만 사용한다.
- 스튜디오 쿠키에는 OS가 발급한 스튜디오 전용 서명 토큰만 저장한다.
- 보호된 요청마다 OS에서 활성 여부·현재 역할·번호 변경 여부를 확인한다. 변경은 다음 요청부터 반영된다.
- OS 연결 실패 시 접근을 거부하며 예전 APP_ROSTER로 우회하지 않는다.
- `/admin/roster`는 OS 계정 관리로 이동한다. OS 관리자 권한은 OS에서만 변경한다.
- 기존 스튜디오 쿠키는 새 로그인으로 전환된다. OS 로그인 세션과 스튜디오 세션은 별도다.
- APP_ROSTER 방식은 비운영 로컬 개발 테스트에만 남아 있다.
- 배포 순서: OS 인증 API 배포 및 정상 응답 확인 → 스튜디오 배포.

인터넷 연결 없이 사용하는 로컬 HTML은 독립 파일이다. OS의 로그인·퇴사자 차단은
웹 스튜디오 접근에 적용되며 이미 내려받은 HTML 파일을 회수하거나 잠그지는 않는다.

검증: `node tests/os-auth-regression.cjs`.
