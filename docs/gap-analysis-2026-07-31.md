## 코드 진단 (2026-07-31 전량 실사, 행번호는 당일 기준)

**구조**: 자연어 → `app/api/chat/route.ts` (gpt-4o-mini function calling, 최대 6라운드) → 조회 계획 JSON → 클라이언트가 `/api/series/*` 병렬 호출 → recharts. 모델은 숫자를 만들지 않는다(유지할 원칙).

1. **국고채 시계열이 프로덕션에서 안 나온다** — `lib/sources/krx.ts:35-48,89-102`가 영업일 1일씩 순회 호출(동시성 3, 지연 300ms). 1년치 ≈ 40~70초 > Vercel 20초 상한(`vercel.json`). 캐시는 `/tmp` 폴백이라 콜드스타트마다 빈다. 로컬 적재분도 18영업일뿐.
   → **해결 확정**: ECOS 817Y002(시장금리, 일별, 1콜)로 대체. item_code는 2026-07-31 실호출로 확정 —
   국고 1년 `010190000` · 2년 `010195000` · 3년 `010200000` · 5년 `010200001` · 10년 `010210000` · 20년 `010220000` · 30년 `010230000` · 회사채 3년 AA- `010300000` · BBB- `010320000` · CD 91일 `010502000` (출처: team-soyoung `weekly_charts.py --discover-items 817Y002`, 2026-07-31)
2. **시리즈 간 연산 전무** — `lib/transforms.ts` 변환(raw/yoy/pop/rebase)은 전부 단일 시리즈 내부(4행 Transform 타입). 스프레드·비율 불가. "10년-3년"은 별도 두 선으로만 그려짐.
3. **이축 없음** — `app/page.tsx:923-930` YAxis 하나, yAxisId 미사용. 단위 다른 지표 겹치면 한 축에 눌림(경고문만, 866행).
4. **소스별 날짜 표기 불일치로 병합 깨짐** — `app/page.tsx:423-434`가 날짜 문자열 완전일치+localeCompare 병합. ECOS 분기 `2026Q2`(정렬 시 맨 뒤로 밀림) vs KOSIS/BLS `2026-07` vs FRED `2026-07-01`. **한·미 비교가 안 되는 직접 원인.**
5. **KOSIS 분기 오독 버그** — `lib/sources/kosis.ts:61,67`: `2026Q2`→`202602`→복원 시 `2026-02`(2월)로 오독. 검색으로 붙는 KOSIS 분기 시리즈는 시점이 통째로 틀린다.
6. **한글 질의면 FRED 검색 통째 스킵** — `lib/search-config.ts:61-67`. "미국 실업률 보여줘"는 미국 쪽 탐색 자체가 안 됨. 검색 대상 소스도 ecos/kosis/fred 3종뿐(`lib/search.ts:64-72`), 챗봇에 넘기는 후보 상위 15건(`app/api/chat/route.ts:175`).
7. **조용한 실패** — 잘못된 itemCode 조합도 ECOS가 200+빈 행 → `lib/sources/ecos.ts:25`가 빈 배열 정상 반환 → UI는 범례만 뜨고 선·오류 없음(`app/page.tsx:436,950-963`).
8. (참고) 챗 계획 스키마(`route.ts:122-147`)에 chartType·축·파생 필드 없음 / 멀티턴 없음 / 질의 로그 저장 없음(`console.log`뿐).

## 승인 범위 (1차 보강 — 이것만)

1. **시리즈 간 파생 계산**(차·비율) + **이축 렌더**(우축 영역형 스프레드 포함) — 챗 계획 스키마에 spread·축 필드 추가
2. **국고 금리 KRX 순회 → ECOS 817Y002 전환** + 위 테너로 카탈로그 확장 (KRX 어댑터는 제거하지 말고 미사용 전환 — 선물지수 등 잔여 용도 확인 후)
3. **날짜 정규화**(병합 전 소스별 표기 통일) + **KOSIS 분기 오독 수정**
4. **FRED 한글 질의 처리**(한글→영문 검색어 변환) + 미국 핵심 지표(실업률·비농업·근원 PCE·소매판매 등) 상시 등록
5. **빈 결과 표면화** — "데이터 없음: <시리즈>" 명시, 200+빈배열의 침묵 금지

**완료 기준 (로컬 실측, 둘 다 실제 렌더 확인)**
- ① "국고 10년이랑 3년 스프레드를 우축 영역형으로 보여줘" → 좌축 두 금리 + 우축 스프레드 영역
- ② "한국 CPI랑 미국 CPI 전년비로 겹쳐줘" → 같은 X축에 정확히 정렬

**보류 목록 (이번에 하지 않는다)**: 질의 로그 저장(2차 후보 1순위), 같은 지표 기간 비교, desk 에이전트 접근(비번 게이트), 멀티턴, 은행채·여전채 이종커브(ECOS 소스 확인부터).
