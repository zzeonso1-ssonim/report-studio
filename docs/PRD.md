# PRD — econ-cockpit (경제데이터 콕핏)

작성일: 2026-07-24 · 작성자: 전소영 · 상태: **초안 (검토 중)**

## 1. 한 줄 정의

한국·미국 공공 경제데이터 API를 한곳에 모아 조회하고, 챗봇에게 자연어로 검색시키는 **개인용** 웹앱.

## 2. 배경 / 문제

- GDP·CPI 나우캐스팅, 채권 스프레드 등 앱이 목적별로 흩어져 있어, "그때그때 보고 싶은 정보"를 확인하려면 여러 앱·포털을 오가야 함.
- CPI·GDP 앱에 각각 챗봇을 심었더니 프롬프트·모델·비용 관리가 분산됨.
- 기관 포털(ECOS, KOSIS, KRX, R-ONE, DART, FreeSIS)마다 인증·포맷·검색 UI가 제각각.

## 3. 사용자

본인 1인 (개인 API 키 사용). **팀 공유 아님** — DAAI·AI OS와 분리.

## 4. 범위

### 포함 (v1)
- 지표 레지스트리 기반 시계열 조회 (지표 선택 → 기간 → 테이블)
- 데이터 소스 어댑터: ECOS, KOSIS, FRED, BLS (동작) / DART 공시검색 (동작) / KRX, R-ONE, FreeSIS, BEA (자리표시자)
- 통합 API: `GET /api/series/{indicatorId}` — 소스 차이를 서버가 흡수

### 포함 (v2)
- **챗봇**: function calling으로 레지스트리를 조회해 알맞은 소스 호출, 자연어 질의 응답
- 차트 시각화
- DART 공시검색 UI

### 제외
- DAAI/AI OS 연동 (팀 자산 — 이 앱은 개인용)
- 계산·추정 로직 일체 (나우캐스팅 등은 기존 엔진이 담당, 이 앱은 **순수 소비자**)
- CPI·GDP 결과 재계산 — 필요 시 기존 엔진의 결과 API만 호출

## 5. 설계 원칙

1. **원천기관 우선**: 중복 지표는 작성기관 API 사용 (CPI→KOSIS, 기준금리·GDP→ECOS, 미 CPI→BLS). 재수록본은 `fallback`으로 지정 가능 — 이중화 수단.
2. **지표 레지스트리 단일 소스**: 지표→소스·코드 매핑은 `lib/indicators.ts` 한 파일에만 존재. 하드코딩 금지 원칙의 적용.
3. **어댑터 계층**: 소스별 인증·포맷·날짜표기 차이는 `lib/sources/*` 어댑터가 흡수. 공통 반환형 `SeriesPoint[]`.
4. **키는 서버 사이드 환경변수만**. 클라이언트 노출 금지.
5. **캐싱 한 겹** (fetch revalidate 10분) — 기관별 일일 호출 한도 보호.

## 7. 챗봇 (v2) 요구사항

- 도구 호출(function calling)로 동작: `list_indicators` → `fetch_series` → 답변 생성. 챗봇이 숫자를 추정·창작하지 않고 **API 결과만 인용**.
- DART 공시검색 도구 별도 (`search_disclosures`).
- 모델·프롬프트·비용 관리는 이 앱 한곳으로 통일. 안정화 후 CPI·GDP 앱에 심어둔 기존 챗봇 코드는 **삭제** (키 비활성화가 아니라 코드 제거, git 히스토리로 복구 가능).

## 8. 비기능 요구사항

- 스택: Next.js (App Router, TS) — 기존 앱들과 통일
- 배포: Vercel 예정이나 **현재 계정 중지(402) 미해결** — 해결 전까지 로컬 개발, 필요 시 대체 호스팅 검토
- 저장소: GitHub private (`econ-cockpit`)
