# PRD — econ-cockpit (경제데이터 콕핏)

작성일: 2026-07-24 · 작성자: 전소영 · 상태: **확정 (v1 구현 중)**

## 1. 한 줄 정의

한국·미국 공공 경제데이터 API를 한곳에 모아 조회하고, 챗봇에게 자연어로 검색시키는 **개인용** 웹앱.

## 2. 배경 / 문제

- GDP·CPI 나우캐스팅, 채권 스프레드 등 앱이 목적별로 흩어져 있어, "그때그때 보고 싶은 정보"를 확인하려면 여러 앱·포털을 오가야 함.
- CPI·GDP 앱에 각각 챗봇을 심었더니 프롬프트·모델·비용 관리가 분산됨.
- 기관 포털(ECOS, KOSIS, KRX, R-ONE, DART, FISIS)마다 인증·포맷·검색 UI가 제각각.

## 3. 사용자

본인 1인 (개인 API 키 사용). **팀 공유 아님** — DAAI·AI OS와 분리.

## 4. 범위

### 포함 (v1)
- 지표 레지스트리 기반 시계열 조회 (지표 선택 → 기간 → 테이블·차트)
- **변환 계층**: 원계열 → 전년동기대비(YoY)·전기대비(QoQ/MoM) 증감률, 재기준화(특정 시점=100). 레지스트리의 주기 정보로 자동 계산 — 추가 API 호출 없음
- **비교 차트**: 복수 지표 겹쳐 그리기 (예: 한국 CPI vs 미국 CPI). 단위가 다른 지표는 YoY% 또는 재기준화로 비교, 주기가 다르면 날짜 정렬 처리
- 데이터 소스 어댑터: ECOS, KOSIS, FRED, BLS (동작) / DART 공시검색 (동작) / KRX, R-ONE, FISIS, BEA (자리표시자)
- 통합 API: `GET /api/series/{indicatorId}?transform=yoy|qoq|mom|rebase` — 소스·변환 차이를 서버가 흡수

### 포함 (v2)
- **챗봇**: function calling으로 레지스트리를 조회해 알맞은 소스 호출, 자연어 질의 응답. 비교·변환 요청도 도구 호출로 처리 ("한미 CPI YoY 비교해줘" → 차트 응답)
- **발표 캘린더**: 지표별 발표 예정일 조회 ("이번 주 발표 뭐 있지?")
  - 미국: FRED `releases/dates` API 자동 (`include_release_dates_with_no_data=true`로 미래 일정 포함)
  - 한국: ECOS·KOSIS 모두 공표일정 API 미제공 (2026-07 확인) → 기관 연간 공표일정을 **캘린더 시드파일**로 연 1회 적재 (금통위 일정 포함). 스크래핑 어댑터는 필요 시 후순위
- DART 공시검색 UI

### 제외
- DAAI/AI OS 연동 (팀 자산 — 이 앱은 개인용)
- 계산·추정 로직 일체 (나우캐스팅 등은 기존 엔진이 담당, 이 앱은 **순수 소비자**)
- CPI·GDP 결과 재계산 — 필요 시 기존 엔진의 결과 API만 호출

## 5. 설계 원칙

1. **원천기관 우선**: 중복 지표는 작성기관 API 사용 (CPI→KOSIS, 기준금리·GDP→ECOS, 미 CPI→BLS). 재수록본은 `fallback`으로 지정 가능 — 이중화 수단.
2. **지표 레지스트리 단일 소스**: 지표→소스·코드 매핑은 `lib/indicators.ts` 한 파일에만 존재. 하드코딩 금지 원칙의 적용.
3. **어댑터 계층**: 소스별 인증·포맷·날짜표기 차이는 `lib/sources/*` 어댑터가 흡수. 공통 반환형 `SeriesPoint[]`.
4. **키는 서버 사이드 환경변수만**. 클라이언트 노출 금지.
5. **캐싱 한 겹** (fetch revalidate 10분) — 기관별 일일 호출 한도 보호.

## 7. 챗봇 (v2) 요구사항

- 도구 호출(function calling)로 동작: `list_indicators` → `fetch_series` → 답변 생성. 챗봇이 숫자를 추정·창작하지 않고 **API 결과만 인용**.
- DART 공시검색 도구 별도 (`search_disclosures`).
- 모델·프롬프트·비용 관리는 이 앱 한곳으로 통일. 안정화 후 CPI·GDP 앱에 심어둔 기존 챗봇 코드는 **삭제** (키 비활성화가 아니라 코드 제거, git 히스토리로 복구 가능).

## 8. 비기능 요구사항

- 스택: Next.js (App Router, TS) — 기존 앱들과 통일
- **UI: AI OS 민트 팔레트로 통일** (primary `#147b6d`, 배경 `#f8fbf9`, 텍스트 `#173b35` — bondAI_OS 테마 기준). 차트 시리즈 색은 색약 검증 팔레트를 별도 사용 (시리즈 구분성 확보). 아키텍처 다이어그램: `docs/ARCHITECTURE.md`
