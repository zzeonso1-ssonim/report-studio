A4 가로형 · 모든 그래프는 이미지로 삽입하며, 원본 비율을 유지함
구성 · 소제목(주제) → 종합판단 → 근거(설명·차트·표). 시사점은 별도 판단이 있을 때만 켜는 선택 요소이며 기본 숨김.
편집 · 편집 모드에서 모든 문구·표·글머리·쪽번호를 직접 수정하고, 모든 그래프는 빈 영역을 클릭하거나 도표를 선택한 뒤 [이미지 넣기/교체]로 수정함. 이미지 안의 축·범례는 원본에서 수정해 다시 넣어야 함. 실수로 삭제·수정했을 때 [실행취소] 또는 ⌘/Ctrl+Z로 되돌리고 [다시실행]으로 재적용함. 기록은 현재 탭에서만 유지되며 HTML·JSON 불러오기와 다시 열기 시 초기화됨. 수정 즉시 브라우저에 자동 저장되며, 보관·전달은 [HTML 저장] 또는 [JSON 백업]을 사용함.
